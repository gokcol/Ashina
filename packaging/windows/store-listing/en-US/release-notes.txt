Ashina 3.1.3

• The app is now named Ashina across the desktop interface, installers, release downloads and Microsoft Store listing.
• Existing installations receive this as an update. Settings, artwork, signatures, review files and editable PDF objects remain compatible.
• Mac updates use the existing trusted signing key and a verified signed feed, with download, install and relaunch support.
• Windows downloads include native x64 and ARM64 builds with offline English, Turkish and German OCR.
• Continues the 3.1 feature freeze, focused on reliability and performance.
